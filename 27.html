7. Project Working Process

  1. User registers with personal information.
  2. User selects Student Pass or Route Pass.
  3. User adds money to the eWallet if a fee is required.
  4. User submits the bus pass application.
  5. Admin verifies and approves the application.
  6. System generates the QR code.
  7. User can renew the pass or buy e-tickets.
  8. Conductor scans the QR code.
  9. Conductor verifies the ticket or pass.
  10. Conductor updates bus location.
  11. User checks estimated travel time.
